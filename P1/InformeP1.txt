Introduccion:
En esta práctica realizaremos el estudio de tres algoritmos distintos para el cálculo del término n-ésimo de 
la secuencia de Fibonacci, cada uno basado en una técnica diferente: recursión directa, iteración y "fast doubling".

El objetivo del estudio es analizar de forma empírica el comportamiento de cada algoritmo a medida que crece el tamaño de la 
entrada, contrastando los tiempos de ejecución medidos frente a distintas cotas teóricas (subestimada, ajustada y sobreestimada),
para comprobar si el comportamiento real se corresponde con la complejidad asintotica asignada a cada uno.
------------------------------------------------------------------------------
Aclaraciones:
    - Todos los resultados de tiempos mostrados en las tablas aparecen representados en microsegundos (µs)
    - Para medir tiempos pequeños de forma precisa, se utiliza un umbral de confianza de 500 µs. Si la medición para un valor
    de n es inferior a dicho umbral, la ejecución se repite 1000 veces y se calcula el tiempo promedio de una ejecución,
    minimizando así los posibles errores.
    - En la tabla, los tiempos a los que se les realizó este proceso aparecen junto a un (*). Esa marca se determina 
    de forma automática durante la ejecución, comparando cada medición individual con el umbral.
    - A mayores, los valores considerados atipicos o anómalos serán marcados con un (+) y serán omitidos del estudio del 
    algoritmo.

Información Fibonacci V1 (algoritmo recursivo)

    Este algortimo utiliza recursion para el calculo del termino n-ésimo que se le indique, tras observar el codigo,
podemos esperar un crecimiento de los tiempos de un orden muy alto debido al acelerado crecimiento del numero de llamadas recursivas.
    Las cotas selecionadas para este algoritmo fueron:
    - Cota subestimada: (1.1)^n | tiende a infinito.
    - Cota ajustada: φ^n |tiende a una constante.
    - Cota sobreestimada:  2^n | tiende a 0.

Información Fibonacci V2 (algoritmo iterativo)

    Este algorimo calcula el termino n-esimo de la secuencia de manera iterativa a trave de un bucle de orden n
 con dos operaciones de tiempo constante, por tanto una cota ajustada lineal es lo mas logico y razonable para este caso.
    Las cotas selecioandas para este algoritmo fueron:
    - Cota subestimada: n^0.8 | tiende a infinito
    - Cota ajustada: n | tiende a una cosntante.
    - Cota sobreestimada: n*log(n) | tiende a 0

Información Fibonacci V3 (algoritmo basado en fast doubling)

    Este algoritmo calcula el termino n-esimo de la secuencia mediante la aplicacion iterativa de un metodo matematico complejo denominado "fast doubling",
 debido a la complejidad del codigo nos resulta dificil comprender cuantas iteraciones realizara el bucle en funcion de n, por tanto nos es imposible estimar previamente la complejidad del algoritmo.
 
    Las cotas seleciandas fueron:
    - Cota subestimada: n^0.5 | tiende a infinito 
    - Cota ajustada: log n | tiende a una cosntante
    - Cota sobreestimada: √(log n) | tiende a 0
